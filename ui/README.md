# PrepForge UI Guide

An interactive web-based reference for the PrepForge UI design specification. This website documents the recommended architecture, layout, and interactive features for transforming PrepForge from a CLI tool into a modern web application.

## Live Demo

Visit: [prepforgeui-aoasqexm.manus.space](https://prepforgeui-aoasqexm.manus.space)

## Sections

1. **Architecture** — CLI-to-web transition plan with layered architecture
2. **Dashboard & Layout** — Core navigation structure with interactive charts (Radar, Line)
3. **Practice Interface** — Mock interview and behavioral session UI features
4. **System Design Canvas** — Interactive whiteboard concept with drag-and-drop components
5. **Rapid-Fire Drills** — Gamified flashcard system with spaced repetition
6. **Tech Stack** — Recommended technologies with priority classifications

## Tech Stack

- React 19 + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Framer Motion (animations)
- Recharts (data visualization)
- Vite (build tool)

## Getting Started

```bash
cd ui
pnpm install
pnpm dev
```

The dev server will start at `http://localhost:3000`.

## Design Philosophy

The UI uses a "Blueprint Craft" aesthetic:
- **Typography:** Instrument Serif (headings) + DM Sans (body) + Fira Code (mono)
- **Colors:** Warm off-white base, deep navy foreground, teal accents
- **Motifs:** Dotted grid backgrounds, numbered sections, architectural precision
